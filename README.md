# Mohammad Nafis Irfan — Academic Portfolio

Jekyll & SCSS academic portfolio modeled after `sbryngelson/academic-website-template`, tailored for Graduate Research Assistant (GRA) applications in Mechanical Engineering and Computational Fluid Dynamics (CFD).

## Quick Setup
1. Create a public GitHub repository named `nafisirfan.github.io`.
2. Upload all files from this archive to the `main` branch.
3. Add your headshot to `assets/img/profile.jpg` (and update `index.html` from `profile.svg` to `profile.jpg`) and place your CV PDF at `assets/pdf/CV.pdf`.
4. Update your LinkedIn, ResearchGate, and GitHub URLs in `_config.yml`.
5. In your repository on GitHub, go to **Settings > Pages > Build and deployment > Source** and select **GitHub Actions**.
